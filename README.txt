GIGACOIN ARENA — STATIC WEBSITE PACKAGE

The existing GigaCoin project site is preserved and now links to a standalone local browser game at /game/.

Official links:
Website: https://gigacoin.onrender.com/
X: https://x.com/GigaSolCoin
Telegram: https://t.me/GigaOfficialCoin

This package is static HTML, CSS, JavaScript, local images, and documentation. No build step, server API, wallet, token payout, or private key is required. Arena Credits are fictional local game points.

See README.md and DEPLOYMENT_GUIDE.md for usage and deployment. Browser runtime gameplay was not validated in the build environment; see TEST_REPORT.md.
